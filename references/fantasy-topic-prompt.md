# Secondary-world fantasy topic-generation prompt

Execute this prompt using the current direction and corresponding candidate count. The direction document is the bundled `fantasy-direction.md`. Instructions are in English; present the outlines in Chinese, with bilingual working titles and the Chinese field labels below.

Read the secondary-world fantasy direction document. Following its definition and criteria, generate complete single-episode outlines for SleepCast.

## Current direction

Insert the user's initial idea here. If none is provided, use "No preset direction".

## Number of outlines

- No preset direction: generate ten different candidates, each with a complete outline.
- An initial direction is provided: develop one complete outline around it.

## Output structure

Use this structure for every outline. Fill the title position with the actual English and Chinese names. Keep the other field labels as shown:

```markdown
# English title / 中文主题名称

## 核心幻想

## 核心体验

## 时间与环境

## 关键规则

## 最终停留状态
```

## Requirements for all outlines

1. The core fantasy is an ordinary, naturally existing phenomenon of this world, not decorative fantasy added to a realistic scene.
2. The core experience specifies what the listener principally experiences. Arrange it chronologically as a complete, continuous route that gradually becomes calmer.
3. Time and environment identify when the experience occurs, its starting point, and its principal spaces.
4. Key rules cover only this episode's experience. Do not explain the fantasy's mechanism or expand world history.
5. The final resting state specifies the listener's location and surrounding conditions at the end.
6. One theme corresponds to one world and one episode.
7. Do not write the full script, divide it into Parts, or add narration, meditation exercises, pauses, or sound design.
8. Existing works in the direction document illustrate the definition and output form. Do not reuse or rewrite their core fantasy.

## Additional requirement for ten candidates

Make the core fantasy, principal environment, and core experience noticeably different across all ten. Fill every field in every candidate; names, brief ideas, or partial outlines are insufficient.
